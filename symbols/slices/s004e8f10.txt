Codegen findings
----------------
* The thiscall originals keep the *data* pointer in ecx and the stream on the stack.
  Free functions taking (data, out) therefore need two stack loads; making the
  wrapper a real member (Rec78Tag::write / Rec30Tag::write / List8::write8 /
  Rec300::write300) reproduces `mov edi, [esp+0x10] ... mov esi, ecx`.
* Keep the `write_vec8(List8*, OutStream*)` name as a thin non-inlined alias so the
  `write_items` call site keeps the original `call rel32`.
* In the member form MSVC hoists the count load before the first vtable call only if the
  loop is written as `int n = this->count; char* a = this->array + 0x28; int i = 0;
  if (n > 0) { do { ...; i++; } while (i < n); }`.
