# Crash ledger

Crash ledger: one row per runtime fault, joined to docs/equiv_verdicts.json for the function's match status. Regenerate docs/crashes.md with `python3 tools/crashes.py --write`.

`status` is the function's equivalence verdict from `docs/equiv_verdicts.json` (PASS / WEAK / FAIL / UNSUPPORTED); `no verdict` means it is byte-exact or not yet judged - `docs/STATUS.md` owns that split.
