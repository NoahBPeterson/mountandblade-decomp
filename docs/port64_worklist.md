(i686, MSVC record rules) through tools/port/port64_ast (libTooling), plus tools/port/find_views.py's view

class is the record the bytes belong to (the cast source, the member's owner); `fn X` groups a function's
locals / parameters, `file X` a file's warnings. Full rows (file:line, function, suggestion) in the TSV;
`--check NAME` prints one class.
